Privacy Policy

Last updated: 5 September 2026

CoN Intel Overlay is an unofficial Chrome extension for drawing intel marks on the Conflict of Nations map. It is not affiliated with Bytro Labs, Dorado Games, or Conflict of Nations.

What we collect

The extension stores your sketches on your computer only, using Chrome’s storage.local API. That data can include:

  • map coordinates of marks you draw
  • stroke type, color, and width
  • optional text labels you type
  • the match id so marks reload in the correct game

It does not collect your name, email, password, payment details, browsing history, or analytics. It does not send sketch data to our servers. There are no servers operated by this extension.

How it is used

Local storage is used only so your marks reappear when you reopen the same match. If you use Export, a JSON file is created on your device for you to share. Import only reads a file you choose.

Sharing

We do not sell, rent, or share user data. Marks leave your computer only if you export a file and send it yourself.

Permissions

  • storage — save and load sketches on this device.
  • conflictnations.com — inject the overlay into the game client. The extension does not run on other websites.

Remote code

The extension does not execute remote code. Overlay logic is shipped inside the package.

Contact

For privacy questions, open an issue on the project repository or contact the developer who published this item on the Chrome Web Store.
